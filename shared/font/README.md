# Bundled fonts

The font binaries in `fonts/` are bundled for server-side OG image generation
(Satori, see `domains/og/`). Each is licensed under the **SIL Open Font License
1.1**; the full license text and the upstream copyright notice / Reserved Font
Name for each is committed alongside it.

| Font              | Binary                        | License                          |
| ----------------- | ----------------------------- | -------------------------------- |
| Schibsted Grotesk | `fonts/SchibstedGrotesk.woff` | `fonts/SchibstedGrotesk.OFL.txt` |
| Noto Sans JP      | `fonts/NotoSansJP-Medium.otf` | `fonts/NotoSansJP.OFL.txt`       |

The `.OFL.txt` files are copied verbatim from each font's upstream distribution
(Google Fonts / fontsource); do not edit the copyright lines.
